# ISLORA

Caribbean travel and experiences platform — **Experience Every Island.**

## MVP
Next.js App Router application deployed on Vercel. Initial release focuses on Jamaica with architecture and brand positioning for Caribbean expansion.

Modules introduced in v0.1: Flights, Island Hopping, Airport Transfers, Rides, Experiences, Beaches, Nightlife, Food, Rentals, Caribbean Roadtrip, Islands and My Trips.

Live inventory, authentication, checkout, flight affiliate APIs and provider/admin systems follow in subsequent phases.
